# Content Guide

Today's Repair should feel calm, specific, and credible.

## Voice

Use:

- plain language
- short sentences
- exact improvements
- honest caveats
- concrete sources

Avoid:

- "good vibes"
- moral lecturing
- vague inspiration
- unsourced claims
- partisan framing
- implying that a problem is solved when it is only improving

## Entry Checklist

Before adding an entry, check:

- Does it describe a real improvement?
- Is the source credible and linked directly?
- Is the summary short enough for an e-ink screen?
- Does the caveat make the entry more honest?
- Would a skeptical user still accept the claim?

## Categories

Suggested category keys:

- `health`
- `climate_repair`
- `energy`
- `education`
- `infrastructure`
- `living_conditions`
- `nature_returns`
- `pollution_repair`
- `science_works`
- `safety`
- `everyday_humanity`

## Good Entry Pattern

```json
{
  "id": "short-stable-id",
  "category": "health",
  "title": "Specific Repair Headline",
  "summary": "One short factual improvement.",
  "why_it_matters": "Why this repair is meaningful without exaggerating.",
  "caveat": "What is still not fixed.",
  "source_name": "Source Organization",
  "source_url": "https://example.com/direct-source",
  "source_checked": "2026-08-29"
}
```
